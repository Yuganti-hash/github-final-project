
# Simple Interest Calculator

## Project Description
This project calculates simple interest based on the principal amount, annual rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Annual rate of interest
- Time period in years

## Technology Used
- Bash scripting
- Linux command line

## How to Run
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Give the script execution permission:
   chmod +x simple-interest.sh
4. Run the script:
   ./simple-interest.sh

## Example
For a principal of 1000, an annual interest rate of 5%, and a time period of 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
